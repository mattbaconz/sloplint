01

What Pingwell does

  • 01.1

    Latency thresholds

    Set a p95 limit in milliseconds per endpoint. Pingwell compares each 30-second check window against it.

  • 01.2

    One engineer paged

    The page goes to whoever is on call by schedule, by phone call or SMS. The rest of the team is not woken up.

  • 01.3

    Confirm before paging

    Require N failed checks in a row, set per monitor, so one slow response does not page anyone at 3 a.m.

  • 01.4

    Rotation schedules

    Weekly handoff for a 2 to 10 person team. If the on-call engineer does not acknowledge in 5 minutes, the next person is paged.

  • 01.5

    Check from outside

    Requests run from outside your network, so you see the latency your users see, with your auth header and request body.
