Alerts that reach one person, fast

Latency thresholds

Set the limit in one line of config

Pingwell checks from three regions and pages only when a majority breach, so one slow region does not wake anyone.

monitor "orders-api" {
  url       = "https://api.example.com/v1/orders"
  interval  = "30s"
  p95_max   = "400ms"
  quorum    = 2          # of 3 regions
  escalate  = "oncall"
}
