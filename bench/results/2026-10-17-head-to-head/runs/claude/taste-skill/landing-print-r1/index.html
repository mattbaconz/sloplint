Records get the same treatment as posters: small runs, nothing reprinted.

Each record ships in a sleeve we print ourselves, with the colour of the vinyl matched to the second ink. When a run is gone, it’s gone.

the studio

Offset Press is one print room and one small label under the same roof. We pull posters on a hand bench, one colour at a time, and we release records by bands we’d buy anyway.

Every run is numbered and capped. When an edition sells out, we reclaim the screens, so a print you own stays a print few others have.
