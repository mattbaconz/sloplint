Built to wake up one person, at the right time

Most alerts are noise. Pingwell only pages when your own limit has been broken and stays broken.

Latency thresholds, not just up or down

A slow API is a broken API to your customers. Set a limit per endpoint on p50, p95, or p99, and we page when it's crossed, even if every request still returns 200.

Pages that reach a person

Phone call, SMS, or push to whoever is on call right now. If they don't acknowledge in five minutes, it moves to the next engineer.

Rotations your team can edit

Build weekly or daily schedules, add overrides for a vacation, and sync with your calendar. Swaps take two clicks.

Confirmed from three regions

A check has to fail from Frankfurt, Virginia, and Singapore before anyone is paged, so one flaky network hop doesn't cost someone their sleep.

Status page included All plans

Works with the tools you already use

Send incidents to Slack, PagerDuty, GitHub Issues, or any webhook. Monitors can be defined in a YAML file and kept in your repo.
