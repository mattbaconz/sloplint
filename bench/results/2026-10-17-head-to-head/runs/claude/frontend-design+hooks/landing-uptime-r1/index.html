30 seconds between checks on every plan.

With 2 consecutive failed checks required before a page, the longest a breach goes unnoticed is about 60 seconds plus delivery time.

What Pingwell does

Latency thresholds

Set p50 or p95 per endpoint, in milliseconds. A page fires only after the number stays over the line for the count of checks you choose.

On-call paging

Pages the person on the current rotation by SMS, voice call or push, then escalates to the next engineer if nobody acknowledges within the window you set.

Multi-region checks

Each endpoint is probed from 3 regions. A page needs a majority to agree, so one bad network path does not wake anyone.

CLI and config file

Define monitors in pingwell.toml and apply them with npx pingwell apply, so thresholds are reviewed in pull requests like the rest of your code.

Webhooks

Every state change is sent as a JSON POST to the URL you register, so incidents can open tickets or post to chat.
