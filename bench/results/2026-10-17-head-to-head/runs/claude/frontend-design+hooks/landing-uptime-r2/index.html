Features, ranked by how often you will use them

5 entries

  • Latency thresholds

    Set a p95 limit per endpoint. Pingwell pages only after the limit is exceeded for the number of consecutive checks you choose, so one slow request does not wake anyone.

    threshold: p95 > 800ms
consecutive_checks: 3

  • On-call paging

    Pages go to whoever is on the rotation right now, by SMS then voice call. If they do not acknowledge, the next person is paged.

  • Config in your repo

    Monitors are defined in a pingwell.yml file, reviewed in pull requests like the rest of your infrastructure.

    - url: https://api.example.dev/v1/search
  method: GET
  every: 60s
  threshold_ms: 800

  • Assertions

    Fail a check on status code or on a missing JSON field, not only on timing.

  • Incident log

    Every page records the failing check, the p95 at the time and who acknowledged it.
