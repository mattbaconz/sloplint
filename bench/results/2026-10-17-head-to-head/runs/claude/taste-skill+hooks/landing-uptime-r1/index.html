01

Alerts fire on latency, not just downtime.

A slow API fails customers before it fails a health check. Set the limit per endpoint.

Threshold per endpoint

Set p95 and the window it must hold over. One slow request never pages anyone.

# pingwell.yml
monitor: GET https://api.example.com/v1/checkout
p95_ms: 300
for: 3 checks
regions: [iad, fra, sin, syd, gru]

On-call rota that pages

Phone call, SMS, then push. If the first engineer does not acknowledge in 5 minutes, the next person on the rota is called.

5 check regions

Checks run from Virginia, Frankfurt, Singapore, Sydney and São Paulo. A page needs at least 2 regions to agree, so one bad network route does not wake anyone.

Timeline per incident

Every page keeps the p95 series, the region breakdown and who acknowledged when, ready to paste into a postmortem.
