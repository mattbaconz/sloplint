Example timeline with illustrative values.

Alerts that reach one person, with the numbers.

  • Latency thresholds, per endpoint

    Set a p50, p95 or p99 limit in milliseconds, for example p95 > 400ms. Pingwell pages after the number of consecutive checks you choose, so one slow request does not wake anyone.

  • On-call rotations

    Weekly or daily shifts with overrides. The page goes to the engineer on shift by phone call, SMS and push, in that order.

  • Escalation after 5 minutes

    If nobody acknowledges, the next person on the rota is paged. You set the delay per service.

  • Checks from 5 regions

    Frankfurt, Virginia, Singapore, Sydney and São Paulo. An alert needs 2 regions to agree, which filters out one flaky network path.

  • Config as code

    Define monitors in a file and apply them from CI: pingwell apply monitors.yml.
