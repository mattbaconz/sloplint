Four things Pingwell does, in order of how often you will use them

01

Latency-threshold paging

Set a p95 limit per endpoint. When it is crossed for the number of consecutive checks you choose, Pingwell calls the person on the rota instead of posting to a channel nobody is watching.

p95 > 400ms
x 2 checks
-> page
02

On-call rotations

Weekly or daily rotations with an override for swaps. If the primary does not acknowledge in 5 minutes, the page escalates to the secondary.

ack_timeout: 5m
escalate: secondary
03

Multi-region probes

Each check runs from 6 regions. A page needs more than one region to agree, so a single bad network path does not wake anyone.

regions: 6
quorum: 2
04

Phone, SMS, Slack, webhooks

Pick the channel per person. Every alert carries the endpoint, the measured p95, the threshold and the region that saw it first.

notify: phone, slack
