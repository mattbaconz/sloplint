The shift desk, for your API

Telegraph offices kept someone awake for the line going quiet. Pingwell is that person for a team with no night shift.

From first check to first page

To begin, add a URL with one command or in the dashboard. Pingwell records a baseline for a day before it can page anyone, so the threshold you set starts from real numbers.

$ pingwell add api.example.com/health --p95 400ms ok monitor created, checking from 12 regions every 30 s baseline: collecting for 24 h

Within a minute, checks run from every region. A single slow reply is ignored; a breach opens only after the number of consecutive checks you chose.

When latency crosses, the person on call gets a phone call with the endpoint, the number and the regions that agree. Two taps acknowledge it; five minutes of silence calls the next engineer.

After that, the timeline records who was paged and when latency came back under the line, and the rotation moves on at the handoff hour.
