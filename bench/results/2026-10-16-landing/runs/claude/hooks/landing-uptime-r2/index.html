What Pingwell does

Latency thresholds

Set a limit on p50, p95 or p99 per endpoint, for example p95 > 400ms. Alerts fire after N consecutive breaches, and N is yours to choose.

On-call paging

Phone call, SMS or push to whoever holds the rotation. If they do not acknowledge in 5 minutes, the next person in the list is paged.

Multi-region checks

Probes run from several regions. A page requires a majority of regions to agree, which filters out a single bad route.

Rotation schedules

Weekly or custom rotations with overrides for holidays and swaps, kept in the time zone of each engineer.

Request assertions

Check status code, a JSON field or a response header along with latency. Add headers for auth, such as Authorization: Bearer ....

Webhooks and API

Send incident events to your own endpoint as JSON, or create monitors from CI with a single authenticated request.
