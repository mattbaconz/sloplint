What Pingwell does, in order of use

4 features
01 · CORE

Page on latency, not just on downtime

Set a p95 threshold per endpoint. When it is exceeded on consecutive checks, Pingwell calls the person on the current on-call rotation instead of posting to a channel nobody is watching.

$ pingwell watch https://api.example.com/v1/orders \
    --p95 500ms --checks 3 --page oncall:primary

  • Multi-region checks 02

    Probe from several regions so one bad route does not page you.

  • On-call schedules 03

    Weekly rotations with an escalation to the secondary after an unacknowledged page.

  • Incident timeline 04

    Each page records the breach time, the acknowledgement time and the recovery time.
