Features

Built for teams of three, not three hundred.

Everything you need to find out first, and nothing that needs a dedicated SRE to configure.

Latency thresholds that mean something

Alert on p50, p95 or p99, per endpoint. Require a breach to last a set window so one slow request never wakes anyone.

Pages the one person on call

Phone call, SMS or push to whoever holds the rotation. If they don't acknowledge, it escalates to the next person automatically.

Multi-region checks

Probes run from 12 regions and must agree before paging, so a flaky network hop doesn't ruin your night.

Rotations in minutes

Weekly or daily schedules, overrides for swaps and holidays, and a calendar feed so everyone sees who's holding the pager.

Authenticated checks

Send headers, bearer tokens and JSON bodies. Assert on status codes and response content, not just reachability.

Status page included

Publish a public status page that updates itself, so your customers stop filing tickets to ask if it's you.
