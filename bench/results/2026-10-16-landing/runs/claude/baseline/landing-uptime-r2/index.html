Features

Built for the one person holding the pager.

Latency thresholds, not just up/down

Alert on p50, p95 or p99 response time per endpoint. Slow is down for your customers, so we treat it that way.

Pages the right person

Rotations and overrides are built in. Pingwell pages whoever is on call right now, then escalates to a backup if nobody responds.

Multi-region confirmation

A breach must show up from several regions before anyone is woken up, which cuts the false alarms that train people to ignore pages.

Monitors as code

Define checks in a YAML file, review them in a pull request, and apply with one CLI command. Or just click around the dashboard.

Slack, SMS, phone, webhooks

Reach people the way they will actually notice. Send incident updates to a channel while the pager goes to a phone.

Incident timeline

Every breach, page and acknowledgement is logged with the latency graph attached, so the postmortem writes itself.
