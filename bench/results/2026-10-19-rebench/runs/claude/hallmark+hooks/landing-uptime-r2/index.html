What happens between a slow response and a page

  • Latency thresholds

    Set a p95 limit per endpoint, in milliseconds. A breach has to hold for a number of consecutive checks you choose, so one slow request does not wake anyone.

  • On-call paging

    Pingwell calls and texts whoever is on the rotation right now. If they have not acknowledged within your timeout, it moves to the next engineer.

  • Rotation schedules

    Weekly or daily rotations with overrides for swaps and leave. Built for teams of two to fifteen, so nobody has to buy an enterprise scheduler.

  • Checks from multiple regions

    Probes run from several regions and a page fires only when more than one region agrees. A bad network path in one place stays a log line.

  • Config as code

    Define monitors in a file, for example pingwell.yml, and apply them from CI so thresholds are reviewed in pull requests.

  • Incident timeline

    Every breach, page, acknowledgement and recovery is recorded with timestamps, ready to paste into a postmortem.
