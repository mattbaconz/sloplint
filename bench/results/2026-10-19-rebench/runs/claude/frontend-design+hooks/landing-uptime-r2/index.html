Built for the one person holding the pager

  • Latency thresholds per endpoint

    Set a p95 limit in milliseconds for each route. /v1/health can allow 400 ms while /v1/search allows 500 ms. Pingwell pages after the limit is crossed on consecutive checks, so one slow response does not wake anyone.

  • Paging that follows your rota

    Import the on-call schedule, or enter it by hand. Pingwell sends an SMS, then calls the phone if nobody acknowledges within 5 minutes, then moves to the next person on the rota.

  • Checks from three regions

    Every endpoint is requested from Frankfurt, Virginia and Singapore. An alert needs at least two regions to agree, so a network fault near one probe does not page you.

  • Incident log with response timings

    Each page records which check crossed the limit, who was paged, and when they acknowledged. Export it as CSV for your post-incident review.

  • Setup from the command line

    Add a check with npx pingwell add, or keep checks in a pingwell.toml file in your repo and apply it from CI.
