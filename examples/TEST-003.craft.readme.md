# Ledgerly

Invoicing for freelancers: turn a week of time entries into a sent PDF invoice with one command.

## Install

```bash
npm install -g ledgerly
```

## Usage

```bash
ledgerly invoice --client fernhill --week 2026-W41
```

Sends the invoice, then reminds the client on day 7 and day 14 if it is unpaid.
