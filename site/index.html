    A design system for every project

    sloplint init writes a DESIGN.md generated from a seed and a one-line brief: a typeface trio, a palette solved for contrast, shape, motion and a layout to follow. The same input always gives the same system, and two rules keep the code on it.

      Four curated presets

      Command line

      Node 20 or newer, no install step, no dependencies. Exit codes are designed for CI.

      sloplint check [paths…]
      Lints JS, TS, JSX, HTML, Vue, Svelte, CSS, Python and Markdown. Prints compiler-style frames with a fix for each finding and a weighted Slop Score, or one line per finding when piped. --fix applies safe autofixes, --changed checks only what changed since the last commit, --format json feeds other tools, --max-score 0 fails the build on any slop.
      sloplint init [--brief text] [--hooks]
      Generates DESIGN.md for the project and syncs the rules it needs into CLAUDE.md, GEMINI.md, AGENTS.md and .cursor/rules/sloplint.mdc. --hooks makes Claude Code lint every file it writes. Your own content in those files is left alone.
      sloplint style [--seed text]
      Previews the system init would generate, as text, JSON or a specimen page, without writing anything else.
      sloplint explain [RULE]
      Prints the rationale and a side-by-side slop and craft diff in the terminal. Without an argument it lists every rule.
      Suppressing a finding
      Add sloplint-disable-next-line UI-007 in a comment, or list paths in .sloplintignore. Suppressions only count inside comments.
